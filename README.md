# TripSetter-AI---A-Multi-Agent-Travel-Planner-with-LangGraph
An intelligent multi-agent AI travel planner built with LangGraph that orchestrates specialized agents for flights, hotels, itineraries, recommendations, budgeting, and travel advice.


# How to run

1. Create the virtual Environment

```bash
conda create -n travel python=3.11 -y
```

2. Activate the Enviroment

```bash
conda activate travel
```

3. Install the requirements

```bash
pip install -r requirments.txt
```
